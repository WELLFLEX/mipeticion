# Seguridad / Security

No publiques vulnerabilidades con datos personales en un issue.

Usa **Security → Report a vulnerability** en GitHub:
https://github.com/WELLFLEX/mipeticion/security/advisories/new

Si el reporte privado aún no está habilitado, abre un issue que diga únicamente «Necesito un canal privado para reportar seguridad», sin detalles técnicos explotables ni datos personales. Un mantenedor debe habilitar el canal antes de pedir detalles.

Incluye versiones afectadas, pasos reproducibles con datos sintéticos e impacto. Nunca adjuntes claves, tokens, documentos reales ni información de una cuenta ajena. No pruebes sobre producción sin coordinación.

Los mantenedores procuran acusar recibo en cinco días hábiles, priorizar según impacto y coordinar la corrección antes de divulgar detalles. Es un objetivo comunitario, no un SLA. Se mantiene la última versión de la rama principal; no hay soporte para instalaciones antiguas.

English: Use GitHub private vulnerability reporting. If unavailable, request a private channel without disclosing the vulnerability. Supply synthetic reproduction steps, affected versions and impact. Do not test production without coordination or share secrets/private cases. Maintainers aim to acknowledge within five business days and coordinate disclosure after remediation.
